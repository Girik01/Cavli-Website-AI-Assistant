      AQ62 Automotive Grade 5G NR Module

      The Cavli AQ62 is an automotive-grade 5G NR Sub-6 GHz module designed for next-generation telematics and connected vehicle applications. Powered by an Arm Cortex A55 quad-core CPU, the AQ62 delivers high-bandwidth and low-latency performance for advanced in-vehicle compute and communication workloads. Its communication subsystem integrates 5G NR connectivity with LTE Cat 18 fallback and supports 3GPP Release 16.

      The AQ62 is available in five regional variants: Worldwide (WW), North America (NA), Eurasia and Japan (EAJ), India (IN), and Eurasia (EA). The module supports multi-constellation GNSS with GPS, GLONASS, Galileo, BeiDou, NavIC and QZSS, along with Qualcomm Location Suite Gen 9VT. Designed for connected mobility applications, the AQ62 is well suited for automotive clusters, vehicle telematics, ADAS systems and OBD solutions.

      Go Beyond and Explore the Cavli AQ62 5G NR IoT Module

      1.

      What is the Cavli AQ62 5G NR automotive module?

      The Cavli AQ62 is an automotive-grade 5G NR Sub-6 GHz smart module designed for next-generation telematics and connected vehicle applications. Powered by an Arm Cortex A55 quad-core CPU, the AQ62 combines in-vehicle compute capabilities with 5G NR connectivity and LTE Cat 18 fallback for automotive communication workloads.
      2.

      What cellular connectivity and 5G speeds does the Cavli AQ62 support?

      The Cavli AQ62 5G NR automotive module supports 5G NR Sub-6 GHz connectivity with LTE Cat 18 fallback and is based on 3GPP Release 16. It supports 5G transmission rates of up to 4.4 Gbps downlink and 900 Mbps uplink with 2T4R, along with LTE 5xCC, NR 4xCC, 2x2 uplink MIMO, 4x4 downlink MIMO, ULCA, DLCA and ENDC.
      3.

      What GNSS and positioning capabilities are supported by the Cavli AQ62?

      The Cavli AQ62 automotive 5G module provides multi-constellation GNSS support for GPS, GLONASS, Galileo, BeiDou, NavIC and QZSS. It supports Qualcomm Location Suite Gen 9VT, with L1 and optional L5 GNSS bands, enabling positioning capabilities for connected vehicle and automotive telematics applications.
      4.

      What automotive applications is the Cavli AQ62 designed for?

      The Cavli AQ62 automotive-grade 5G module is designed for automotive clusters, vehicle telematics, ADAS systems and OBD solutions. Its combination of 5G NR connectivity, LTE Cat 18 fallback, GNSS and onboard processing makes it suitable for connected mobility applications requiring cellular communication and in-vehicle compute capabilities.
      5.

      What hardware interfaces does the Cavli AQ62 5G module provide?

      The Cavli AQ62 5G module provides a broad set of hardware interfaces, including UART, USIM, USB, SDC, I2C, SPI, I2S, PCM, RGMII/SGMII/USxGMII, PCIe, GPIO and antenna interfaces. The module includes four UART interfaces, two USIM interfaces, two SDC interfaces, two I2C interfaces, two SPI interfaces, three I2S interfaces, one PCM interface and nineteen GPIOs.
      6.

      Which regional variants of the Cavli AQ62 are available?

      The Cavli AQ62 5G NR module is available in five regional variants based on supported cellular frequency bands: Worldwide (WW), North America (NA), Eurasia and Japan (EAJ), India (IN), and Eurasia (EA). These variants support regional deployment requirements for automotive telematics and connected vehicle applications.
      7.

      Does the Cavli AQ62 support VoLTE, VoNR and NG-eCall?

      Yes. The Cavli AQ62 automotive connectivity module supports both VoLTE and VoNR. The module also supports NG-eCall as an optional feature, along with optional QDR 3.0 support.
      8.

      What processor, memory and operating system does the Cavli AQ62 use?

      The Cavli AQ62 automotive-grade 5G smart module is powered by an Arm Cortex A55 processor operating at up to 2 GHz. It supports 4/8 Gb RAM with 4/8 Gb Flash memory and runs Linux/TelSDK, with OpenSDK support.
